## 📚 Algoritmos implementados

### 🔹 1. Busca Binária (`busca_binaria.py`)
Algoritmo eficiente para encontrar um item em uma lista ordenada, dividindo a busca pela metade a cada iteração.

**Exemplo:**
```python
numeros = [1, 3, 5, 7, 9]
print(busca_binaria(numeros, 7))  # Saída: 3
````

---

### 🔹 2. Ordenação por Seleção (`ordenacao_selecao.py`)

Percorre a lista várias vezes, encontrando o menor valor e movendo-o para o início, até que toda a lista esteja ordenada.

**Exemplo:**

```python
print(ordenacao_por_selecao([5, 3, 6, 2, 10]))  # Saída: [2, 3, 5, 6, 10]
```

---

### 🔹 3. Máximo em uma Lista (`max_lista.py`)

Função recursiva que percorre uma lista e retorna o maior valor contido nela.

**Exemplo:**

```python
print(max_lista([1, 5, 10, 25, 3]))  # Saída: 25
```
